# Notebook 1.6.1 verification

Baseline: clean `dev` at `0f48573`, fetched and fast-forward checked before edits.

## Changes

- GitHub release Markdown is normalized for KOReader's plain TextViewer:
  headings, bold, code fences and inline links become readable text; identical
  URL labels are not repeated.
- Export controls are at the bottom. Selection uses dark full thumbnail borders,
  while unselected borders are gray; current reading page no longer affects
  export selection. Removed checkbox glyphs. Range instructions explain `-`
  and `,`, wrap to available width and are translated in all 13 catalogs.
- Oversized ink is clipped to thumbnail paper rather than covering page labels.
- Filled marker contours have a small bounds index shared by area erasing,
  whole-stroke hit tests and dirty repaint. Mutations invalidate the index.
  Distant contours bypass polygon construction and clipping. Half-plane
  subtraction reuses immutable polygons lying entirely on one side.
- README documents tested device scope, optional integrations and source versus
  packaged installation for contrib discoverability.

## Evidence and limits

`make ci`: lint, 46 configured Lua suites, catalog completeness/checks,
16 Python benchmark tests and ZIP integrity/contents verification.
Regression tests reproduce unreadable Markdown and excessive dirty-contour
raster calls before changes. Geometry suites check independent distance
oracles, preserved underlying ink, undo/redo and scaled save/load.

Native `check-updates-ui.lua`: real KOReader widget layout and range dialog,
600×800 offscreen, with screenshots inspected. Export actions are at the bottom,
selected tiles have black borders and unselected tiles gray borders.

Native desktop BB8 repaint comparison, 1001-point curved marker after 12 cuts,
45×55 dirty rectangle: 4.085 ms before, 2.179 ms after (1.87×), identical pixels.

Native cut/undo/redo benchmark, twelve cuts on 1001-point curved markers:

CPU/offscreen measurements, not end-to-end e-ink latency or a new physical
Kindle smoke test. No refresh cadence or file format change is claimed.
