# Notebook 1.6.2 verification

- Synchronized clean dev with origin before edits, starting at v1.6.1.
- Reproduced the missing native Markdown option with a regression exercising
  `updater.check(true)` through the private loader, rather than just testing a
  formatter in isolation. Registered the fallback formatter in the loader.
- Update notes now use KOReader TextViewer's native `md` format where supported.
  Older TextViewer versions receive simplified plain text. Both callback paths
  are tested; the private module test also checks release-note loading.
- Native `tools/check-release-notes-ui.lua` exercises production policy,
  transport completion and offer, using a disposable future-release fixture.
  The real HTML viewer renders headings, bold, lists, inline code, links and
  quotes. Screenshot inspected at 600×800. No raw Markdown in generated HTML.
- `make ci` passed: lint, all 46 configured Lua suites, catalog checks, 16 Python
  benchmark tests and packaged contents/integrity.
- README documents installation from release assets and copying `lua/` directly,
  source archives versus plugin archives, complete replacement, icons/locales,
  preserved notebook storage and restart after upgrades.
- No new geometry/rendering change or device performance claim in this patch.

The screen offering this release is produced by the previously installed
plugin. Its appearance only changes after installing the patch and restarting
KOReader. A v1.6.1 installation that fails to open the offer due to the missing
private formatter can be upgraded using the release ZIP or source-copy method.
